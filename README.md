# Taxi Macerata

Sito statico responsive per Taxi Macerata / Domenico Menduni. Non richiede build, framework o dipendenze: `index.html`, `styles.css` e `script.js` possono essere pubblicati direttamente.

## Anteprima locale

Apri `index.html` nel browser, oppure avvia un server statico dalla cartella:

```sh
python -m http.server 8080
```

## Pubblicazione

Pronto per Vercel: importa la cartella/repository come progetto **Other**, senza build command e con output directory `.`. È incluso `vercel.json`. In alternativa, GitHub Pages può pubblicare i file statici dalla root del branch.
